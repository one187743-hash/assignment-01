# Seedling – 5-page Tailwind website
Open `index.html` in a browser (needs internet for Tailwind CDN + Google Fonts).
- `*.html` – Home, About, Contact, Sign In, Sign Up
- `assets/img/favicon.svg` – favicon
- `assets/js/layout.js` – shared navbar/footer; `forms.js` – form handling; `tw-config.js` – theme
Contact form: replace `YOUR_EMAIL@example.com` in contact.html with your real email. The first submission sends an activation email from FormSubmit; click its link once, then messages arrive in your inbox. Works on the live GitHub Pages site (not by double-clicking the file).
